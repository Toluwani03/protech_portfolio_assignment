# protech_portfolio_assignment

Welcome to my personal portfolio! This project showcases my skills, projects, and journey as a developer.

## About the Project

This is a personal portfolio website designed to introduce me, highlight the technologies I work with, showcase my projects, and provide a way to get in touch.

The website features a clean, minimalist design with a focus on simplicity, accessibility, and responsiveness.

## Built With

- HTML5
- CSS3

## Features

- Introduction and personal profile section
- About Me section
- Projects showcase 
- Skills and technologies section
- Contact form
- Responsive navigation
- Interactive hover effects

## Getting Started

To view the project locally:

1. Clone this repository:

   ```bash
   git clone "https://github.com/Toluwani03/protech_portfolio_assignment"
   ```

2. Navigate to the project folder:

   ```bash
   cd portflio_assignment
   ```

3. Open `index.html` in your browser.
