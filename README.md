# protech_portfolio_assignment

Welcome to my personal portfolio! This project showcases my skills, projects, and journey as a developer.

## About the Project

This is a personal portfolio website designed to introduce me, highlight the technologies I work with, showcase my projects, and provide a way to get in touch.

The website features a clean, minimalist design with a focus on simplicity, accessibility, and responsiveness. It also includes interactive JavaScript features and a Post Explorer that fetches real articles from the DEV.to API.

## Built With

- HTML5
- CSS3
- JavaScript
- DEV.to API

## Features

- Introduction and personal profile section
- About Me section
- Projects showcase
- Skills and technologies section
- Contact form with JavaScript validation
- Responsive navigation
- Dark and light theme toggle with saved preference
- Dynamically generated project cards
- Post Explorer displaying articles from the DEV.to API
- Search functionality for articles by title and description
- Loading and error messages for API requests
- Interactive hover effects
- Responsive layout for different screen sizes

## Getting Started

To view the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/Toluwani03/protech_portfolio_assignment.git
   ```

2. Navigate to the project folder:

   ```bash
   cd protech_portfolio_assignment
   ```

3. Open `index.html` in your browser.
